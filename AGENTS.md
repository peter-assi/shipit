# Agent instructions

When adding, renaming, or removing an image in this repository:

- Update `README.md` in the same change so the gallery renders every tracked image exactly once.
- Keep gallery entries in filename order. Use a relative image path and descriptive alt text, and show the filename beneath each image.
- Check that every gallery path resolves to a tracked file and that no tracked image is missing.
- Record the source, creator, license, and any transformations in `ASSET_SOURCES.md` when adding an image that needs attribution.
